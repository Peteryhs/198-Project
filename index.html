03One set: send, score, receive

A repetition is one movement and return. A set is the group between Start and Done, such as 10 elbow bends. Every wire record ends with a newline.

  1. BEFORE STARTWait with no sensor stream.

    Python must be listening. Do not begin another set while a previous one awaits its final verdict.

  2. ARDUINO → PYTHON · STARTSend one header; reset sequence and set clock.
    #TALLY2 fs=100 unit=g range=3 side=L

    Paired format · every 10 ms · acceleration in g · ±3 g range · left arm. Use side=R for the right arm. Python sends no header acknowledgement.

  3. ARDUINO → PYTHON · EVERY 10 MILLISECONDSRead both sensors together; send all six values on one line.
    S sequence time_ms upper_x upper_y upper_z forearm_x forearm_y forearm_z
    S 0 0 +0.05123456 -0.01834567 +0.99321234 +0.10769876 -0.02915432 +0.97180000
    S 1 10 +0.05123456 -0.01834567 +0.99321234 +0.10769876 -0.02915432 +0.97180000

    Sequence +1; actual elapsed milliseconds must increase. Calibrated g, gravity included; signed values with eight decimals. Continue between repetitions. Keep sample lines ≤128 characters; no debug text on this link.

  4. ARDUINO → PYTHON · DONEStop sampling, arm the receiver, then send one end marker.
    E done

    Not after each repetition. For cancellation send E aborted; for lost samples send E overflow. These discard the set.

  5. PYTHON → ARDUINO · AFTER DONERead every R line, then the final V line.

    Python now finds repetitions and scores them. These are end-of-set results, not live exercise cues.

Results arrive in this order

FIRST · ALL REPETITIONS, IN ORDER
R 1 correct 0.100 EFE 2.000
R 2 wrong 0.800 EFE 1.900
R 3 correct 0.200 EFE 2.100
→
LAST · WHOLE SET
V correct 0.367 EFE

Average wrong-form score: (0.100 + 0.800 + 0.200) ÷ 3. This V completes the set.

RecordFields after the marker
R · repetitionRep number (starts at 1), estimated verdict, wrong-form probability, exercise code, duration in seconds.
V · setFinal verdict, mean wrong-form probability, majority exercise code. Not an average across multiple sets.
V unknown nan -Handled validation failure, cancelled set, or fewer than three detected cycles. No R lines for an unscorable set.

Wrong at probability ≥0.5; use the returned verdict because printed scores are rounded. A “correct” set can contain flagged reps. The mean is not the percentage of reps done correctly. Individual-rep accuracy is not independently validated: training labels describe whole sets.

Exercise meanings are in §5. results.jsonl stores all rep fields and set diagnostics (overwritten at launch); verdicts.log appends the R/V lines.

04Integrate the receiver into your firmware

One code package below. It supplies both processRepVerdict() and processVerdict(), plus their shared reader. Do not replace your sketch, setup(), or loop().

  1. Paste once: add the entire package above your existing setup(). Everything is inside the ModelResults namespace.
  2. Initialize: call Serial1.begin(115200) once in your setup(). Keep Serial.begin(115200) for the supplied USB debug prints, or remove those prints for operation without USB output.
  3. Connect Done: stop acquisition. Call ModelResults::beginWait(); if it returns true, send E done. Use the same guard for E aborted / E overflow.
  4. Receive: call ModelResults::poll() frequently in your loop. If your firmware already assembles UART lines, call ModelResults::acceptLine(line) instead. Use only one Serial1 reader.
  5. Display or forward: edit onRep() and onSet() in this package. Block Start while recording or while ModelResults::busy() is true.

You call beginWait() and poll() (or acceptLine()). The receiver calls processRepVerdict() and processVerdict() automatically. You edit onRep() and onSet() for the OLED or forwarding.

Full receiver code · both verdict functions + merge-point guide
Paste once. The merge-point guide is at the bottom of this block.
#include <Arduino.h>
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

namespace ModelResults {
struct RepResult {
  unsigned long index;
  bool wrong;
  float pWrong;
  float durationS;
  char exercise[4];
};
static RepResult latestRepResult = {};
static char repVerdictLine[64] = "";
static char verdictLine[40] = "";
static unsigned long receivedRepCount = 0;
static bool awaitingVerdict = false;
static unsigned long verdictWaitStartMs = 0;
static char replyInputLine[64];
static size_t replyInputLength = 0;
static bool discardReplyLine = false;

// Add OLED/save/forwarding code here. Do not delay() in these callbacks.
static void onRep() {
  Serial.print(F("# "));
  Serial.println(repVerdictLine);
  // latestRepResult: index, wrong, pWrong, exercise, durationS.
  // Called for every rep; the next rep replaces these stored values.
}
static void onSet() {
  Serial.print(F("# "));
  Serial.println(verdictLine);
  // verdictLine holds the complete final V result, including unknown.
}
static void note(const __FlashStringHelper *message) {
  Serial.print(F("# "));
  Serial.println(message);
}
static bool busy() { return awaitingVerdict; }
static bool timedOut() {
  return awaitingVerdict && millis() - verdictWaitStartMs >= 30000UL;
}
// Call once, immediately BEFORE sending E done / E aborted / E overflow.
static bool beginWait() {
  if (awaitingVerdict) return false;
  receivedRepCount = 0;
  latestRepResult = RepResult{};
  repVerdictLine[0] = verdictLine[0] = '\0';
  replyInputLength = 0;
  discardReplyLine = false;
  verdictWaitStartMs = millis();
  awaitingVerdict = true;
  return true;
}

static void processVerdict(char *line) {
  char tag[4] = {0}, verdict[16] = {0}, probability[16] = {0},
       exercise[16] = {0}, trailing = '\0';
  char *end = NULL;
  bool shapeOk = sscanf(line, "%3s %15s %15s %15s %c", tag, verdict,
                        probability, exercise, &trailing) == 4 &&
    strcmp(tag, "V") == 0 &&
    (strcmp(verdict, "correct") == 0 || strcmp(verdict, "wrong") == 0 ||
     strcmp(verdict, "unknown") == 0);
  bool probabilityOk = false;
  bool exerciseOk = shapeOk && (strcmp(exercise, "EAH") == 0 ||
                    strcmp(exercise, "EFE") == 0 || strcmp(exercise, "SQZ") == 0);
  if (shapeOk && strcmp(verdict, "unknown") == 0) {
    probabilityOk = strcmp(probability, "nan") == 0 && strcmp(exercise, "-") == 0;
  } else if (shapeOk) {
    double p = strtod(probability, &end);
    probabilityOk = end != probability && *end == '\0' && isfinite(p) &&
                    p >= 0.0 && p <= 1.0 && exerciseOk;
  }
  if (shapeOk && probabilityOk && awaitingVerdict) {
    strncpy(verdictLine, line, sizeof(verdictLine) - 1);
    verdictLine[sizeof(verdictLine) - 1] = '\0';
    awaitingVerdict = false;
    onSet();
  } else {
    note(F("ignored invalid or unsolicited verdict"));
  }
}

static void processRepVerdict(char *line) {
  char tag[3] = {}, number[16] = {}, verdict[16] = {}, probability[16] = {},
       exercise[8] = {}, duration[16] = {}, trailing = '\0';
  bool shapeOk = sscanf(line, "%2s %15s %15s %15s %7s %15s %c", tag, number,
                        verdict, probability, exercise, duration, &trailing) == 6;
  if (!awaitingVerdict || !shapeOk || strcmp(tag, "R") != 0 ||
      (strcmp(verdict, "correct") != 0 && strcmp(verdict, "wrong") != 0) ||
      (strcmp(exercise, "EAH") != 0 && strcmp(exercise, "EFE") != 0 &&
       strcmp(exercise, "SQZ") != 0) || number[0] == '\0' ||
      strspn(number, "0123456789") != strlen(number)) {
    note(F("ignored invalid or unsolicited rep result"));
    return;
  }
  unsigned long index = strtoul(number, NULL, 10);
  char *pEnd = NULL, *dEnd = NULL;
  double probabilityValue = strtod(probability, &pEnd);
  double durationValue = strtod(duration, &dEnd);
  if (index != receivedRepCount + 1 || pEnd == probability || *pEnd != '\0' ||
      dEnd == duration || *dEnd != '\0' || !isfinite(probabilityValue) ||
      probabilityValue < 0 || probabilityValue > 1 ||
      !isfinite(durationValue) || durationValue <= 0 || durationValue > 600) {
    note(F("ignored invalid or out-of-order rep result"));
    return;
  }
  latestRepResult.index = index;
  latestRepResult.wrong = strcmp(verdict, "wrong") == 0;
  latestRepResult.pWrong = (float)probabilityValue;
  latestRepResult.durationS = (float)durationValue;
  strcpy(latestRepResult.exercise, exercise);
  strcpy(repVerdictLine, line); // Caller supplies a bounded, complete line.
  receivedRepCount = index;
  verdictWaitStartMs = millis(); // Valid progress restarts the inactivity timer.
  onRep();
  // OLED / forwarding hook: latestRepResult holds this rep's estimated result.
  // Stay awaitingVerdict: only the final V line completes the set.
}

// Use this entry point if YOUR firmware already reads Serial1.
// Pass one complete, null-terminated line; do not also call poll().
static void acceptLine(const char *line) {
  if (!line) return;
  char complete[64];
  size_t n = 0;
  while (n < sizeof(complete) && line[n] != '\0') ++n;
  if (n == 0 || n >= sizeof(complete)) return;
  memcpy(complete, line, n);
  while (n > 0 && (complete[n-1] == '\r' || complete[n-1] == '\n')) --n;
  complete[n] = '\0';
  if (strncmp(complete, "R ", 2) == 0) processRepVerdict(complete);
  else if (strncmp(complete, "V ", 2) == 0) processVerdict(complete);
}

static void poll() {
  // The tally script's reply arrives on the same UART that carries samples.
  // Bound work per loop and discard overlong lines through their newline.
  for (uint8_t processed = 0; processed < 16 && Serial1.available() > 0; ++processed) {
    char c = (char)Serial1.read();
    if (c == '\r') continue;
    if (c == '\n') {
      if (!discardReplyLine) {
        replyInputLine[replyInputLength] = '\0';
        acceptLine(replyInputLine);
      }
      replyInputLength = 0;
      discardReplyLine = false;
    } else if (discardReplyLine) {
      continue;
    } else if (replyInputLength + 1 < sizeof(replyInputLine)) {
      replyInputLine[replyInputLength++] = c;
    } else {
      replyInputLength = 0;
      discardReplyLine = true;
      note(F("reply line too long; discarded"));
    }
  }
}

} // namespace ModelResults

/* MERGE POINTS — add these statements to YOUR existing handlers.
   Do not paste a second setup() or loop().

   Existing setup(), once:
     Serial1.begin(115200);
     Serial.begin(115200);  // Optional USB diagnostics used by onRep/onSet.

   Existing Start event:
     If already recording or ModelResults::busy() is true, ignore Start.
     Otherwise send the header and begin your existing 10 ms sample loop.

   Existing Done event, AFTER stopping sample transmission:
     if (ModelResults::beginWait()) Serial1.println("E done");
     For Cancel/failure, use the same guard and E aborted / E overflow.

   Existing loop(), called frequently without delay:
     ModelResults::poll();
     If ModelResults::timedOut(), show Unable to score; keep Start locked.

   Alternative when your existing UART reader already assembles lines:
     ModelResults::acceptLine(yourCompleteLine);
     Use this INSTEAD of poll().

   Edit onRep() and onSet() above for your OLED/save/forwarding output.
   Handle each onRep() immediately; the next rep overwrites latestRepResult.
   Timeout recovery: restart Python AND reset Arduino before the next set.
*/

Inside ModelResults, latestRepResult holds index, wrong, pWrong, exercise and durationS. Only the latest rep stays in Arduino RAM: save/forward each onRep() call to keep all results. Do not delay inside callbacks. The raw set result stays in verdictLine.

No result? ModelResults::timedOut() becomes true after 30 seconds without a valid result while waiting. Show “Unable to score” and keep Start locked. Restart Python and reset Arduino together before retrying; there are no transaction IDs. Runtime startup failures may send no V at all.

06Check the integration

  • A valid, scorable set produces R 1…R n in order, then exactly one V. onRep() runs for every accepted rep; onSet() runs once at the end.
  • Cancel or an insufficient set produces only V unknown nan -. The OLED shows “Unable to score”.
  • Start is blocked while waiting. Timeout does not silently start the next set.
  • On the actual hardware: verify sensor calibration/orientation, power, pin conflicts, UART levels, and a sustained 10 ms sampling interval.

Verified on host: Python parser tests and the receiver extracted from this HTML. Arduino-core compilation, OLED integration and shield runtime still need target testing. Python does not repair missing samples.
