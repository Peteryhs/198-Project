Tally armband · firmware handoff

Stream a set, get a verdict back

Your sketch samples two ADXL335 accelerometers and streams each set to a Python script on the shield. When the set ends, the script replies with a verdict for every repetition and one for the whole set.

1Mount and wire the sensors

  • Mount both boards on the outer side of the same arm, as drawn.
  • Report each axis in g with gravity included.

Axes, standing with arms down

Xup
Yfront to back
Zside to side

Calibrate first. The sketch's ADC-to-g conversion, (ADC-338)*0.0148, is inherited and uncalibrated. Calibrate each axis on your own board before you trust the reported g.

2Start the script on the shield

Copy these files into /root/tally on the shield:

  • scripts/tally_stdlib.py
  • scripts/stdlib_runtime.py
  • model/paired-synchronized-offline/L/realtime_model.npz
  • model/paired-synchronized-offline/R/realtime_model.npz

Two weight files, one per arm. Left and right are separate files of about 2 KB each. Copy both, and the header's side=L or side=R decides which one scores the set. If your build only ever records one arm, add --side L (or R) to reject the other.

Then run:

cd /root/tally
python3 -B -u scripts/tally_stdlib.py \
  --port /dev/ttyATH0 \
  --quiet \
  --out /tmp/tally-results.jsonl \
  --reply both \
  --reply-file /tmp/tally-verdicts.log
  • The link runs at 115200 8N1. The script listens on /dev/ttyATH0, the shield end of the sketch's Serial1 link. It sends its reply lines back on that same link and keeps a copy in /tmp/tally-verdicts.log. Results for each set go to /tmp/tally-results.jsonl.
  • It prints a ready line when it can accept a set. Don't send anything before you see it.
  • It records nothing until the sketch sends a header, so you can leave it running between sets.

3Run a set

Send these commands to the sketch over USB serial. The sketch writes the matching line on Serial1.

You sendSketch sends
START L / START RThe header with side=L or side=R, then sample lines
STOPE done
ABORTE aborted, which discards the set
nothingE overflow when the set reaches 60,000 samples

A set can last at most 600 s. Record a longer session as several sets.

Exact lines on Serial1

Once per set:

#TALLY2 fs=100 unit=g range=3 side=L

Every 10 ms, one paired sample, upper arm first:

S <seq> <t_ms> <ux> <uy> <uz> <fx> <fy> <fz>

Exactly one end marker:

E done | E aborted | E overflow
  • seq starts at 0 and goes up by 1. t_ms always increases.
  • Write every value with eight decimals.
  • Keep each line under 128 characters.
  • Send no debug text on Serial1. Use USB serial for that.

4Read the replies

After the end marker, the shield replies on the same UART the samples went out on. Each repetition gets one R line:

R 1 correct 0.100 EFE 2.000
Rrepetition line
1rep number
corrector wrong
0.100p_wrong
EFEexercise code
2.000duration in s

One V line closes the set:

V <verdict> <mean_p_wrong> <exercise>
Vset line
verdictcorrect or wrong
mean_p_wrongmean over reps
exerciseexercise code
  • A p_wrong of 0.5 or more means wrong. Use the verdict word rather than re-thresholding the printed number.
  • If the set can't be scored, the only reply is V unknown nan -, with no R lines. That happens when the set is rejected, or when fewer than 3 repetitions were found.

5Exercise codes

The exercise field of R and V holds one of these codes.

EFE

Elbow flexion. Bend the elbows and straighten them again, upper arms kept still.

EAH

Arms over head. Raise both arms overhead, then lower them.

SQZ

Squeeze. Squeeze and release with the hands, arms held out in front.

6Paste the receiver into your sketch

Paste the whole block below above your existing setup(). It lives in namespace ModelResults, so your own setup() and loop() stay as they are. In setup(), add Serial1.begin(115200);. Then hook it in at four places:

  1. On START L / START R: ignore the command while a set is still waiting for its V line. 
    if (ModelResults::busy()) return;  // then send the header and start sampling
  2. Before every end marker: stop sampling, then arm the receiver and send the marker. Use the same guard for E aborted and E overflow. 
    if (ModelResults::beginWait()) Serial1.println("E done");
  3. In loop(): call ModelResults::poll() on every pass, without delays. If your sketch already assembles Serial1 lines, pass each complete line to ModelResults::acceptResultsLine(line) instead. Use one or the other, not both. If ModelResults::timedOut() returns true (30 s with no reply), show that the set couldn't be scored, then restart the shield script and reset the Arduino before the next set.
  4. Edit onRep() and onSet(): put your display or forwarding code here. onRep() runs once per R line, with the parsed fields in latestRepResult. The next rep overwrites them, so handle each one right away. onSet() runs once with the full V line in verdictLine. Don't call delay() in either.
Receiver code 
#include <Arduino.h>
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

namespace ModelResults {
struct RepResult {
  unsigned long index;
  bool wrong;
  float pWrong;
  float durationS;
  char exercise[4];
};
static RepResult latestRepResult = {};
static char repVerdictLine[64] = "";
static char verdictLine[40] = "";
static unsigned long receivedRepCount = 0;
static bool awaitingVerdict = false;
static unsigned long verdictWaitStartMs = 0;
static char replyInputLine[64];
static size_t replyInputLength = 0;
static bool discardReplyLine = false;

// Add OLED/save/forwarding code here. Do not delay() in these callbacks.
static void onRep() {
  Serial.print(F("# "));
  Serial.println(repVerdictLine);
  // latestRepResult: index, wrong, pWrong, exercise, durationS.
  // Called for every rep; the next rep replaces these stored values.
}
static void onSet() {
  Serial.print(F("# "));
  Serial.println(verdictLine);
  // verdictLine holds the complete final V result, including unknown.
}
static void note(const __FlashStringHelper *message) {
  Serial.print(F("# "));
  Serial.println(message);
}
static bool busy() { return awaitingVerdict; }
static bool timedOut() {
  return awaitingVerdict && millis() - verdictWaitStartMs >= 30000UL;
}
// Call once, immediately BEFORE sending E done / E aborted / E overflow.
static bool beginWait() {
  if (awaitingVerdict) return false;
  receivedRepCount = 0;
  latestRepResult = RepResult{};
  repVerdictLine[0] = verdictLine[0] = '\0';
  replyInputLength = 0;
  discardReplyLine = false;
  verdictWaitStartMs = millis();
  awaitingVerdict = true;
  return true;
}

static void processVerdict(char *line) {
  char tag[4] = {0}, verdict[16] = {0}, probability[16] = {0},
       exercise[16] = {0}, trailing = '\0';
  char *end = NULL;
  bool shapeOk = sscanf(line, "%3s %15s %15s %15s %c", tag, verdict,
                        probability, exercise, &trailing) == 4 &&
    strcmp(tag, "V") == 0 &&
    (strcmp(verdict, "correct") == 0 || strcmp(verdict, "wrong") == 0 ||
     strcmp(verdict, "unknown") == 0);
  bool probabilityOk = false;
  bool exerciseOk = shapeOk && (strcmp(exercise, "EAH") == 0 ||
                    strcmp(exercise, "EFE") == 0 || strcmp(exercise, "SQZ") == 0);
  if (shapeOk && strcmp(verdict, "unknown") == 0) {
    probabilityOk = strcmp(probability, "nan") == 0 && strcmp(exercise, "-") == 0;
  } else if (shapeOk) {
    double p = strtod(probability, &end);
    probabilityOk = end != probability && *end == '\0' && isfinite(p) &&
                    p >= 0.0 && p <= 1.0 && exerciseOk;
  }
  if (shapeOk && probabilityOk && awaitingVerdict) {
    strncpy(verdictLine, line, sizeof(verdictLine) - 1);
    verdictLine[sizeof(verdictLine) - 1] = '\0';
    awaitingVerdict = false;
    onSet();
  } else {
    note(F("ignored invalid or unsolicited verdict"));
  }
}

static void processRepVerdict(char *line) {
  char tag[3] = {}, number[16] = {}, verdict[16] = {}, probability[16] = {},
       exercise[8] = {}, duration[16] = {}, trailing = '\0';
  bool shapeOk = sscanf(line, "%2s %15s %15s %15s %7s %15s %c", tag, number,
                        verdict, probability, exercise, duration, &trailing) == 6;
  if (!awaitingVerdict || !shapeOk || strcmp(tag, "R") != 0 ||
      (strcmp(verdict, "correct") != 0 && strcmp(verdict, "wrong") != 0) ||
      (strcmp(exercise, "EAH") != 0 && strcmp(exercise, "EFE") != 0 &&
       strcmp(exercise, "SQZ") != 0) || number[0] == '\0' ||
      strspn(number, "0123456789") != strlen(number)) {
    note(F("ignored invalid or unsolicited rep result"));
    return;
  }
  unsigned long index = strtoul(number, NULL, 10);
  char *pEnd = NULL, *dEnd = NULL;
  double probabilityValue = strtod(probability, &pEnd);
  double durationValue = strtod(duration, &dEnd);
  if (index != receivedRepCount + 1 || pEnd == probability || *pEnd != '\0' ||
      dEnd == duration || *dEnd != '\0' || !isfinite(probabilityValue) ||
      probabilityValue < 0 || probabilityValue > 1 ||
      !isfinite(durationValue) || durationValue <= 0 || durationValue > 600) {
    note(F("ignored invalid or out-of-order rep result"));
    return;
  }
  latestRepResult.index = index;
  latestRepResult.wrong = strcmp(verdict, "wrong") == 0;
  latestRepResult.pWrong = (float)probabilityValue;
  latestRepResult.durationS = (float)durationValue;
  strcpy(latestRepResult.exercise, exercise);
  strcpy(repVerdictLine, line); // Caller supplies a bounded, complete line.
  receivedRepCount = index;
  verdictWaitStartMs = millis(); // Valid progress restarts the inactivity timer.
  onRep();
  // OLED / forwarding hook: latestRepResult holds this rep's estimated result.
  // Stay awaitingVerdict: only the final V line completes the set.
}

// Use this entry point if YOUR firmware already reads Serial1.
// Pass one complete, null-terminated line; do not also call poll().
static void acceptResultsLine(const char *line) {
  if (!line) return;
  char complete[64];
  size_t n = 0;
  while (n < sizeof(complete) && line[n] != '\0') ++n;
  if (n == 0 || n >= sizeof(complete)) return;
  memcpy(complete, line, n);
  while (n > 0 && (complete[n-1] == '\r' || complete[n-1] == '\n')) --n;
  complete[n] = '\0';
  if (strncmp(complete, "R ", 2) == 0) processRepVerdict(complete);
  else if (strncmp(complete, "V ", 2) == 0) processVerdict(complete);
}

static void poll() {
  // The tally script's reply arrives on the same UART that carries samples.
  // Bound work per loop and discard overlong lines through their newline.
  for (uint8_t processed = 0; processed < 16 && Serial1.available() > 0; ++processed) {
    char c = (char)Serial1.read();
    if (c == '\r') continue;
    if (c == '\n') {
      if (!discardReplyLine) {
        replyInputLine[replyInputLength] = '\0';
        acceptResultsLine(replyInputLine);
      }
      replyInputLength = 0;
      discardReplyLine = false;
    } else if (discardReplyLine) {
      continue;
    } else if (replyInputLength + 1 < sizeof(replyInputLine)) {
      replyInputLine[replyInputLength++] = c;
    } else {
      replyInputLength = 0;
      discardReplyLine = true;
      note(F("reply line too long; discarded"));
    }
  }
}

} // namespace ModelResults
