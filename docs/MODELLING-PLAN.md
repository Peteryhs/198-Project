# One-page modelling decision — before training

**Recommendation:** export two regularized linear classifiers over the existing three-axis accelerometer features, with exercise identity and a provisional quality score, and return “not enough evidence to say” for error type. **Confidence: high** on fit-to-memory; **medium** on series-level generalization; **low/unproven** on live repetitions and patient transfer.

**Labels and timing.** Exercise names come from filenames; correct/wrong labels belong to whole sensor recordings. The quality model inherits those labels for training and averages probabilities for the only validated verdict: the completed recording. Per-repetition scores remain unvalidated. An unlabelled error head stays absent. A repetition cannot be fully recognized before completion. Existing segmentation additionally uses centered smoothing, whole-recording percentiles, and future peaks: its benchmark is offline, not a latency result. A causal detector and bounded post-completion delay need a separate replay experiment.

**Pre-training budget (estimates).** Four output rows × (31 weights + bias) × 4 bytes = **512 B coefficients**, with scaling folded into weights. Budget **8 KiB added flash**, **12 KiB added RAM**, and **10,000 cycles = 0.208 ms** at 48 MHz for arithmetic, excluding four unmeasured `expf` calls and detection/features. A possible RAM allocation is 500 samples × 3 axes × 4 = 6,000 B buffer, 124 B features, 16 B scores, 512 B accumulator allowance, 1,024 B detector state and 4,096 B stack = **11,772 B**. The five-second cap is a proposed limit; longer repetitions must abstain, and it does not implement the current offline detector. These are allocation targets, not measured device use. Cross-compile the exported classifier if possible; measure MCU latency/RAM later. No neural runtime or 12-channel buffer is required.

**Experiment fixed now.** Fixed seed; all volunteers grouped in outer LOSO; scaling and fits use training subjects only; print the training-majority predictor floor beside every accuracy. Evaluate the existing unweighted logistic baseline, equal-recording-weight heads, duration-only ablation, and nested training-subject learning curves without selecting hyperparameters on test folds. Report recording-level exercise/quality accuracy and per-subject results, never repetition accuracy. Expect quality within five percentage points of the existing logistic baseline (**forecast**, not a measurement); worse held-subject results or a flat/declining learning curve would argue against this choice. Recognition has no verified prior here; do not promise an accuracy.

**Sensor mismatch.** Use acceleration only; each input is one three-axis sensor stream, not fused gyro/magnetometer or four-sensor angles. Mixed-placement matrices preserve the old comparison; a known upper-arm placement needs a separate subset check. If raw recordings are available, clip each acceleration axis to ±3 g **before** detection/features and rerun LOSO. Summary matrices cannot reconstruct clipping. The local sample can test the code path only. Twelve analog signals still require hardware multiplexing or a digital-sensor decision.

**Rejected alternatives.** A large shared CNN/RNN plus an error head lacks error targets and adds capacity/porting work; a genuinely small sequence model remains untested, not disproven. Attention/max-pooling MIL can localize saliency but cannot validate correctness or invent causes; retain mean pooling for this baseline. Synthetic error labels/automatic tempo or posture rules would conflate a chosen definition with observed clinical truth; require prescribed targets and independently checked labels first. Existing forests remain comparison artifacts but require a separate bounded export to fit flash.

**Smallest new-data proposal (owner decision).** First label synchronized video and sensor data from a small supervised pilot: six volunteers × three exercises × ten repetitions = **180 repetitions**, with boundaries, correctness, error category or “not observable,” and two independent raters. Include normal execution and safely supervised examples; report raw agreement and Cohen's kappa before training a category classifier. This is a feasibility pilot, not sufficient clinical validation. Agree observable categories first; effort is not directly identified by these sensors. Hold out people, not repetitions.

**Owner decisions:** approve patient-facing wording and clinical scope; choose sensor/interface and placement; decide whether to fund the annotation pilot and raw-data download. No such decision is presumed by this experiment.
