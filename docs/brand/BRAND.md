# form — brand sheet

Working brand for the ECE 198 exercise-monitoring device. Everything here is generated by
`make_brand.py`; the SVG files are the source of truth and the PNGs are renders.

## The name

**form**, always lowercase in the wordmark. It names exactly what the device judges — the form a
person's repetition takes — and it reads as a normal word to a seventy-year-old.

Rejected, with reasons:

| Name | Why not |
| --- | --- |
| Tally | Reads as bookkeeping, and collides with an accounting software brand. |
| Steady | Collides with a US Medicare company, and promises a reliability the prototype has not earned. |

## The mark

A baseline that swells into one repetition and returns to it. Drawn as a **single continuous
path** (`bar, hump, bar`), so there is no overlapping stroke cap where the hump meets the floor —
that seam was the visible flaw in the first attempt.

- Canvas 512, clear margin 88, stroke 42, round caps and joins.
- Path: `M 128 376 L 168 376 A 88 88 0 0 1 344 376 L 384 376`
- At 32 px and one bit it still reads: measured 31 black pixels in a 20 × 10 bbox, i.e. a solid
  hump, not a smear.

First-round directions that were rejected: a chevron of two limb segments (read as a caret), a
free-floating arc (read as a cropped letter "n"), an open ring with a sensor dot (read as a
capital "C"), and a stepped tally stroke (read as a malformed "u").

## Colour

| Role | Name | Hex | Contrast on paper |
| --- | --- | --- | --- |
| Type, mark, device body | Ink | `#1C1917` | 15.4 : 1 |
| Ground, band print | Paper | `#F5F0E6` | — |
| The one accent that carries the system | Clay | `#9A3B12` | 6.1 : 1 |
| A repetition done well | Sage | `#3F5A46` | 6.7 : 1 |
| Secondary labels only | Ash | `#6B6157` | 5.3 : 1 |

All four text colours clear WCAG AA (4.5 : 1) on paper with room to spare. Ratios are computed in
`make_brand.py`, not estimated. Clay is the only accent; sage exists solely as a state colour for
"this rep was good" and must never become a second brand colour.

## Type

- **Fraunces** (semibold, tight tracking) — wordmark and headline. A warm serif is the deliberate
  choice: every other student project will be a geometric sans.
- **Inter** (semibold for numbers) — counts, labels, instructions. Counts at 56 px on a screen
  the size of a kitchen tile, because the reader is older.

## Tagline

**Good form counts.**

Two readings in three words: it tallies repetitions, and it takes form seriously.

Alternates, if this one is too dry: *Every rep, honestly.* / *Form worth keeping.*

## Regenerate

```bash
cd ~/work/phytmo/brand
uv run --no-project python make_brand.py
```

Fonts used by the renders: Fraunces and Inter, both installed under
`~/.local/share/fonts`. Without them the renders fall back to Helvetica and the wordmark will
overflow — install them before re-rendering.
