ECE 198 · Tally armband · firmware ↔ model handoff

Record one set. Get one estimate per rep, then one set verdict.

Two accelerometers on one arm. Arduino samples at 100 Hz. Python on the shield scores after the set ends.

01 · SensorsBoth sensors on the same arm.

One ADXL335 above the elbow, one below, both on the outer side. That pairing is what the model was trained on.

ADXL335 ±3 g. Readings are nominal, uncalibrated g, gravity included. Values above 3 g pass through unchanged.

Verify on the bench before the first recording.

02 · Start PythonThree files. One command.

The shield side is standard library only. No NumPy, no SciPy, no scikit-learn, no install step.

  1. Copy three files into /root/tally: scripts/tally_stdlib.py, scripts/stdlib_runtime.py, and realtime_model.npz. About 30 KB for both arms combined.
  2. Run one command. 
    cd /root/tally && python3 -B -u scripts/tally_stdlib.py \
  --port /dev/ttyATH0 --quiet --out /tmp/tally-results.jsonl \
  --reply both --reply-file /tmp/tally-verdicts.log
  3. Wait for the ready line, then let the firmware send the #TALLY2 header. For unattended use, start it with the supplied procd unit rather than a manual shell.

Runtime: Python 3.10, OpenWrt on AR9331 (shield side). The Arduino UNO R4 Minima handles sampling only.

03 · ProtocolOne set: send, then receive.

A set is everything between Start and E done. A session is one or more sets. The firmware caps a set at 60,000 samples = 600 s, so a 60-minute session is six sets.

  1. Arduino → Python · Header One header per set. Reset the sequence and set clock.
    #TALLY2 fs=100 unit=g range=3 side=L

    Use side=R for the right arm. No acknowledgement is sent. Every wire record ends with a newline.

  2. Arduino → Python · Every 10 ms Read both sensors, send all six values on one line.
    S <seq> <t_ms> ux uy uz fx fy fz
    S 0 0 +0.05123456 -0.01834567 +0.99321234 +0.10769876 -0.02915432 +0.97180000 S 1 10 +0.05234567 -0.01923456 +0.99187654 +0.10876543 -0.02876543 +0.97203456

    seq increments by 1. t_ms is actual elapsed milliseconds and must increase. Eight decimal places, signed. Keep each line ≤128 characters. No debug text on this UART.

  3. Arduino → Python · End marker Stop sampling, arm the receiver, then send exactly one.
    E done

    E aborted on cancel / non-finite readings / missed sampling deadline. E overflow at the 60,000-sample cap. Both discard the set and produce V unknown nan -.

  4. Python → Arduino · After E Every R line arrives in rep order, then one V closes the set.

    Python finds repetitions and scores them once. These are end-of-set results, not live cues.

Results arrive in this order

First · every rep, in order
R 1 correct 0.100 EFE 2.000
R 2 wrong 0.800 EFE 1.900
R 3 correct 0.200 EFE 2.100
Last · the whole set V correct 0.367 EFE

Mean wrong-form score: (0.100 + 0.800 + 0.200) ÷ 3. This V closes the set.

Parse one R line

R 1 correct 0.100 EFE 2.000
Rrep record
rep #1 (starts at 1)
verdictcorrect / wrong
p_wrong0.000 – 1.000
exerciseEAH · EFE · SQZ
durationseconds

Reference

RecordFields after the marker
R · repetitionrep # (from 1), verdict, p_wrong, exercise code, duration s
V · setfinal verdict, mean p_wrong, majority exercise code
V unknown nan -Validation failure, cancelled set, or fewer than three detected cycles. No R lines precede it.

Rep is wrong at p_wrong ≥ 0.5; always trust the returned verdict, not the printed probability (rounded). A “correct” set can contain flagged reps; the mean is not the percent of reps done correctly. Per-rep output is an estimate: training labels describe whole sets, not individual repetitions.

04 · Receiver codePaste once into your firmware.

One C++ package. Supplies both verdict handlers and their shared reader. Do not replace your sketch, setup() or loop().

  1. Paste once: add the entire package above your existing setup(). Everything lives inside the ModelResults namespace.
  2. Initialize: call Serial1.begin(115200) in setup(). Keep Serial.begin(115200) for USB diagnostics, or remove those prints.
  3. At Done: stop acquisition. Call ModelResults::beginWait(); if it returns true, send E done. Same guard for E aborted / E overflow.
  4. In your loop: call ModelResults::poll() frequently. If your firmware already assembles UART lines, use ModelResults::acceptLine(line) instead. Only one reader.
  5. Display or forward: edit onRep() and onSet(). Block Start while ModelResults::busy() is true.

#include <Arduino.h>
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

namespace ModelResults {
struct RepResult {
  unsigned long index;
  bool wrong;
  float pWrong;
  float durationS;
  char exercise[4];
};
static RepResult latestRepResult = {};
static char repVerdictLine[64] = "";
static char verdictLine[40] = "";
static unsigned long receivedRepCount = 0;
static bool awaitingVerdict = false;
static unsigned long verdictWaitStartMs = 0;
static char replyInputLine[64];
static size_t replyInputLength = 0;
static bool discardReplyLine = false;

// Add OLED/save/forwarding code here. Do not delay() in these callbacks.
static void onRep() {
  Serial.print(F("# "));
  Serial.println(repVerdictLine);
  // latestRepResult: index, wrong, pWrong, exercise, durationS.
  // Called for every rep; the next rep replaces these stored values.
}
static void onSet() {
  Serial.print(F("# "));
  Serial.println(verdictLine);
  // verdictLine holds the complete final V result, including unknown.
}
static void note(const __FlashStringHelper *message) {
  Serial.print(F("# "));
  Serial.println(message);
}
static bool busy() { return awaitingVerdict; }
static bool timedOut() {
  return awaitingVerdict && millis() - verdictWaitStartMs >= 30000UL;
}
// Call once, immediately BEFORE sending E done / E aborted / E overflow.
static bool beginWait() {
  if (awaitingVerdict) return false;
  receivedRepCount = 0;
  latestRepResult = RepResult{};
  repVerdictLine[0] = verdictLine[0] = '\0';
  replyInputLength = 0;
  discardReplyLine = false;
  verdictWaitStartMs = millis();
  awaitingVerdict = true;
  return true;
}

static void processVerdict(char *line) {
  char tag[4] = {0}, verdict[16] = {0}, probability[16] = {0},
       exercise[16] = {0}, trailing = '\0';
  char *end = NULL;
  bool shapeOk = sscanf(line, "%3s %15s %15s %15s %c", tag, verdict,
                        probability, exercise, &trailing) == 4 &&
    strcmp(tag, "V") == 0 &&
    (strcmp(verdict, "correct") == 0 || strcmp(verdict, "wrong") == 0 ||
     strcmp(verdict, "unknown") == 0);
  bool probabilityOk = false;
  bool exerciseOk = shapeOk && (strcmp(exercise, "EAH") == 0 ||
                    strcmp(exercise, "EFE") == 0 || strcmp(exercise, "SQZ") == 0);
  if (shapeOk && strcmp(verdict, "unknown") == 0) {
    probabilityOk = strcmp(probability, "nan") == 0 && strcmp(exercise, "-") == 0;
  } else if (shapeOk) {
    double p = strtod(probability, &end);
    probabilityOk = end != probability && *end == '\0' && isfinite(p) &&
                    p >= 0.0 && p <= 1.0 && exerciseOk;
  }
  if (shapeOk && probabilityOk && awaitingVerdict) {
    strncpy(verdictLine, line, sizeof(verdictLine) - 1);
    verdictLine[sizeof(verdictLine) - 1] = '\0';
    awaitingVerdict = false;
    onSet();
  } else {
    note(F("ignored invalid or unsolicited verdict"));
  }
}

static void processRepVerdict(char *line) {
  char tag[3] = {}, number[16] = {}, verdict[16] = {}, probability[16] = {},
       exercise[8] = {}, duration[16] = {}, trailing = '\0';
  bool shapeOk = sscanf(line, "%2s %15s %15s %15s %7s %15s %c", tag, number,
                        verdict, probability, exercise, duration, &trailing) == 6;
  if (!awaitingVerdict || !shapeOk || strcmp(tag, "R") != 0 ||
      (strcmp(verdict, "correct") != 0 && strcmp(verdict, "wrong") != 0) ||
      (strcmp(exercise, "EAH") != 0 && strcmp(exercise, "EFE") != 0 &&
       strcmp(exercise, "SQZ") != 0) || number[0] == '\0' ||
      strspn(number, "0123456789") != strlen(number)) {
    note(F("ignored invalid or unsolicited rep result"));
    return;
  }
  unsigned long index = strtoul(number, NULL, 10);
  char *pEnd = NULL, *dEnd = NULL;
  double probabilityValue = strtod(probability, &pEnd);
  double durationValue = strtod(duration, &dEnd);
  if (index != receivedRepCount + 1 || pEnd == probability || *pEnd != '\0' ||
      dEnd == duration || *dEnd != '\0' || !isfinite(probabilityValue) ||
      probabilityValue < 0 || probabilityValue > 1 ||
      !isfinite(durationValue) || durationValue <= 0 || durationValue > 600) {
    note(F("ignored invalid or out-of-order rep result"));
    return;
  }
  latestRepResult.index = index;
  latestRepResult.wrong = strcmp(verdict, "wrong") == 0;
  latestRepResult.pWrong = (float)probabilityValue;
  latestRepResult.durationS = (float)durationValue;
  strcpy(latestRepResult.exercise, exercise);
  strcpy(repVerdictLine, line); // Caller supplies a bounded, complete line.
  receivedRepCount = index;
  verdictWaitStartMs = millis(); // Valid progress restarts the inactivity timer.
  onRep();
  // OLED / forwarding hook: latestRepResult holds this rep's estimated result.
  // Stay awaitingVerdict: only the final V line completes the set.
}

// Use this entry point if YOUR firmware already reads Serial1.
// Pass one complete, null-terminated line; do not also call poll().
static void acceptLine(const char *line) {
  if (!line) return;
  char complete[64];
  size_t n = 0;
  while (n < sizeof(complete) && line[n] != '\0') ++n;
  if (n == 0 || n >= sizeof(complete)) return;
  memcpy(complete, line, n);
  while (n > 0 && (complete[n-1] == '\r' || complete[n-1] == '\n')) --n;
  complete[n] = '\0';
  if (strncmp(complete, "R ", 2) == 0) processRepVerdict(complete);
  else if (strncmp(complete, "V ", 2) == 0) processVerdict(complete);
}

static void poll() {
  // The tally script's reply arrives on the same UART that carries samples.
  // Bound work per loop and discard overlong lines through their newline.
  for (uint8_t processed = 0; processed < 16 && Serial1.available() > 0; ++processed) {
    char c = (char)Serial1.read();
    if (c == '\r') continue;
    if (c == '\n') {
      if (!discardReplyLine) {
        replyInputLine[replyInputLength] = '\0';
        acceptLine(replyInputLine);
      }
      replyInputLength = 0;
      discardReplyLine = false;
    } else if (discardReplyLine) {
      continue;
    } else if (replyInputLength + 1 < sizeof(replyInputLine)) {
      replyInputLine[replyInputLength++] = c;
    } else {
      replyInputLength = 0;
      discardReplyLine = true;
      note(F("reply line too long; discarded"));
    }
  }
}

} // namespace ModelResults

/* MERGE POINTS — add these statements to YOUR existing handlers.
   Do not paste a second setup() or loop().

   Existing setup(), once:
     Serial1.begin(115200);
     Serial.begin(115200);  // Optional USB diagnostics used by onRep/onSet.

   Existing Start event:
     If already recording or ModelResults::busy() is true, ignore Start.
     Otherwise send the header and begin your existing 10 ms sample loop.

   Existing Done event, AFTER stopping sample transmission:
     if (ModelResults::beginWait()) Serial1.println("E done");
     For Cancel/failure, use the same guard and E aborted / E overflow.

   Existing loop(), called frequently without delay:
     ModelResults::poll();
     If ModelResults::timedOut(), show Unable to score; keep Start locked.

   Alternative when your existing UART reader already assembles lines:
     ModelResults::acceptLine(yourCompleteLine);
     Use this INSTEAD of poll().

   Edit onRep() and onSet() above for your OLED/save/forwarding output.
   Handle each onRep() immediately; the next rep overwrites latestRepResult.
   Timeout recovery: restart Python AND reset Arduino before the next set.
*/
No result after 30 s ModelResults::timedOut() flips true. Show “Unable to score” and keep Start locked. Restart Python and reset Arduino together before retrying — there are no transaction IDs. Startup failures may send no V at all.

Guarantees in the shield build

Strict framingReads at most 512 bytes at a time; keeps at most 129 bytes of a line; discards oversized frames through the next newline.
One verdict per setHeader supersedes earlier state. Orphan or duplicate markers are ignored. Any failed check yields V unknown nan -, never an invented score.
Set expiry2 s without a complete record, or 610 s total, ends the set.
Sensor healthAll-zero, constant, or stuck channels are rejected with a named diagnostic. No clamping: readings above 3 g pass through.
Bounded logsPer path: 128 KiB current + 128 KiB backup on /tmp tmpfs (volatile; not a durable ledger).
Owns the portNon-blocking flock preflight. If anything else holds the UART, the parser refuses to start.
Deadlines after EScoring cut at 20 s; whole reply cut at 25 s. Replies hit the wire before any file log.
Session vs setFirmware cap: 60,000 samples = 600 s at 100 Hz. Six capped sets ≈ 60 min. E overflow ends a set cleanly; no Python restart needed.
